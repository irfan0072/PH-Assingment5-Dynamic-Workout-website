# FitLog

FitLog is a dark-themed workout library and training planner built with Next.js. It pulls workout data from a public API, lets users browse exercises, save items for later, and build a daily plan with a clean and responsive dashboard layout.

## Technologies Used
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- localStorage for persistence
- Public fitness API integration

## Key Features
1. Responsive workout library with searchable/sortable cards
2. Workout detail pages with metadata, instructions, and plan actions
3. My Plan dashboard with today’s plan and saved list management
4. Add-to-plan, save-for-later, and mark-as-done interactions with toast feedback
5. Custom 404 page and polished dark UI matching the provided design direction

## Project Overview
This app follows the FitLog assignment requirements for a modern workout library. Users can review workouts, open detailed instructions, add sessions to their plan, and keep track of their progress using a compact schedule-style interface.

## Getting Started

